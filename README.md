# 预期养老金计算器

一个纯前端的中国城镇职工基本养老金估算工具。输入个人账户、缴费记录、退休地和出生信息后，估算退休时的基础养老金与个人账户养老金，并折算为当前购买力。

## 功能

- 城市专用参数、23 个省级地区通用参数及自定义退休地参数
- 按出生年月和职工类别计算渐进式延迟法定退休年月
- 支持弹性退休与特殊情况的手动退休时间
- 广东低平均缴费指数修正
- 北京 N 应缴断缴月数进入平均缴费指数分母
- 个人账户记账利率、后续缴费和通胀假设
- 名义养老金与当前购买力对照
- 浅色、深色和跟随系统主题
- 桌面端与移动端响应式布局

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

开发服务器默认使用 `http://localhost:3000`。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## 技术栈

React 19、TypeScript、Vite、Tailwind CSS、Radix UI、Recharts。

## 隐私

所有计算均在浏览器本地完成，不需要后端或账号。参数草稿和主题偏好仅保存在当前浏览器的 `localStorage`，不会上传，也不会跨设备同步；清除浏览器数据会丢失。

## 计算口径

本工具按企业职工基本养老保险的基础养老金和个人账户养老金两项公式进行静态估算，不含过渡性养老金及地方补充待遇。地方基准、退休资格和实际待遇以退休时当地社保经办机构核定为准。非整数退休年龄的计发月数采用相邻整数档位线性折算，仅供测算。

政策原文和官方查询入口已列在应用页面底部。
